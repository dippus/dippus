### 🚀 About Me

I am a passionate **Mobile & Systems Software Engineer** specializing in **Native Android (Kotlin & Jetpack Compose)** and **Cross-Platform Engineering (React Native & TypeScript)**. 

- 🔒 **Privacy-First Advocate**: I build tools with zero telemetries, zero tracking, and true 100% offline-first reliability.
- ⚡ **Tactile & Responsive Engineering**: Obsessed with 60–120 FPS buttery smooth interfaces, tuned ERM haptic feedback, and low-latency audio pipelines.
- 🛠️ **Full-Lifecycle Developer**: From architecture design and zero-allocation data structures (Trie, Spaced Repetition) to production release workflows.
