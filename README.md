### 🚀 Engineering Profile

I am a **Mobile & Systems Software Engineer** specializing in **Cross-Platform Architecture (React Native & TypeScript)** and **Native Android Systems (Kotlin & Jetpack Compose)**.

My engineering philosophy centers on **predictable performance, clean architectural boundaries, and verifiable proof-of-work**:

* ⚡ **Performance & Frame Budget:** Obsessed with consistent 60–120 FPS rendering, FlatList virtualization optimization, and minimal JavaScript-to-Native bridge latency.
* 🔒 **Offline-First Resilience:** Prioritizing zero-network dependencies for core flows using fast C++ native key-value storage (**MMKV**), cached synchronization (**TanStack Query**), and centralized state (**Zustand**).
* 🛠️ **Full Engineering Lifecycle:** Owning mobile products from system design and UI hierarchy down to standalone compilation (EAS / Gradle) and production Google Play Store publishing.
