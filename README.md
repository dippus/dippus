### 🚀 About Me

I am a **Full-Lifecycle Mobile App Developer** specializing in **Cross-Platform Mobile (React Native & TypeScript)** and **Native Android Systems (Kotlin & Jetpack Compose)**. 

I take product ideas from **scratch (0) all the way to a published app on the Google Play Store (1)**—managing UI/UX architecture, state management, native sensors, and production release pipelines end-to-end.

* 📱 **The "APK-on-Phone" Standard:** I build production-grade apps verified directly on physical hardware with instant live performance.
* ⚡ **Fluid 60–120 FPS UI:** Obsessed with buttery smooth gesture navigation, micro-interactions, tuned haptic feedback, and zero frame drops.
* 🔒 **Offline-First & High Performance:** Fast C++ native local persistence (**MMKV** / SQLite), smart server caching (**TanStack Query**), and lightweight state (**Zustand**).
* 🚢 **Complete Release Engineering:** EAS Standalone builds, Keystore code-signing, Google Play Console compliance, and production `.aab` publishing.
