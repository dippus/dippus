### 🚀 About Me

I am an **Android App Developer** specializing in **Native Android Development (Kotlin & Jetpack Compose)** and **Cross-Platform Mobile Apps (React Native & TypeScript)**.

I build production-grade Android applications from scratch and manage the complete app lifecycle all the way to **Google Play Store launch**:

* 🤖 **Native Android Mastery:** Deep expertise in Kotlin, Jetpack Compose modern UI, Android SDK components, and Android OS Services (`InputMethodService`, Audio, Haptics).
* ⚡ **Fluid 60–120 FPS Experience:** Obsessed with buttery smooth gesture navigation, Material Design 3, responsive Flexbox layouts, and zero frame drops.
* 🔒 **Offline-First & High Performance:** Fast native local persistence (**Room DB / MMKV**), reactive state architecture, and zero-telemetry privacy.
* 🚢 **Complete Play Store Lifecycle:** Keystore code signing, APK / AAB compilation, Google Play Console guidelines, and production release deployment.
